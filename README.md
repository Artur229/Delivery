# Delivery

Food delivery web application with a customer storefront, cart, checkout, admin dashboard, chef workspace, and courier console.

## Live Demo

[Open the site](https://delivery-site-ten.vercel.app)

## Stack

- SvelteKit frontend
- Hono backend
- PostgreSQL with Drizzle ORM
- WebSocket updates for order activity

## Local Development

Backend:

```bash
npm install
npm run dev
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
